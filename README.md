# SIMAT Sako SIT Lampung - System Web

Sistem Informasi Manajemen Anggota Terpadu (SIMAT) Sako SIT Provinsi Lampung.

## Cara Publish via GitHub Pages (Dalam 1 Menit)

1. Buka Repositori GitHub ini.
2. Klik tab **Settings** di bagian atas.
3. Pilih menu **Pages** di sidebar sebelah kiri.
4. Pada bagian **Build and deployment > Branch**:
   - Pilih Branch: `main`
   - Pilih Folder: `/ (root)`
5. Klik tombol **Save**.
6. Tunggu 1-2 menit, situs akan otomatis terpublikasi di alamat:
   `https://USERNAME.github.io/simat-sako-lampung/`
